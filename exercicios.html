T1Tutoria · BMH e BMHS com o último casamento

Faça os módulos long BMH(...) e long BMHS(...) que retornem a posição no texto T em que ocorreu o último casamento do padrão P (primeiro caractere na posição 1; sem casamento, retorne 0).

Ver resolução

Os dois são o código do slide com três mudanças: retorno long, variável ultima e return ultima. Entre BMH e BMHS só mudam as linhas marcadas com *.

/* T: texto    n: tamanho do texto */
/* P: padrão   m: tamanho do padrão */
/* i: fim da janela   k: posição em T */
/* j: posição em P   d: tabela de deslocamentos */
long BMH(TipoTexto T, long n, TipoPadrao P, long m)
{ long i, j, k, d[MAXCHAR + 1], ultima = 0;
  for (j = 0; j <= MAXCHAR; j++) d[j] = m;              /* * */
  for (j = 1; j < m; j++) d[P[j-1]] = m - j;            /* * */
  i = m;
  while (i <= n)
  { k = i;  j = m;
    while (j > 0 && T[k-1] == P[j-1]) { k--; j--; }
    if (j == 0) ultima = k + 1;
    i += d[T[i-1]];                                     /* * */
  }
  return ultima;
}

/* T: texto    n: tamanho do texto */
/* P: padrão   m: tamanho do padrão */
/* i: fim da janela   k: posição em T */
/* j: posição em P   d: tabela de deslocamentos */
long BMHS(TipoTexto T, long n, TipoPadrao P, long m)
{ long i, j, k, d[MAXCHAR + 1], ultima = 0;
  for (j = 0; j <= MAXCHAR; j++) d[j] = m + 1;          /* * */
  for (j = 1; j <= m; j++) d[P[j-1]] = m - j + 1;       /* * */
  i = m;
  while (i <= n)
  { k = i;  j = m;
    while (j > 0 && T[k-1] == P[j-1]) { k--; j--; }
    if (j == 0) ultima = k + 1;
    i += d[T[i]];                                       /* * */
  }
  return ultima;
}

P = "MIA", T = "AUTONOMIA DA IA NA GRECIA", k = 1 (inserção, substituição e retirada). Mostre a tabela M, preencha o teste de mesa e indique as posições de casamentos exatos e aproximados.

T5Tutoria · Shift-And só com inserção

Altere o código do Shift-And aproximado para retornar as ocorrências exatas e as aproximadas com k erros de apenas inserção.

Ver resolução 
/* k: máximo de erros   R[j]: máscara com j erros */
/* Ri: 10^(m-1), liga o 1º bit */
/* Rant: R[j-1] antigo   Rnovo: R novo */
/* Masc: máscaras   i: índice no C (de 0) */
Ri = 1 << (m - 1);
for (i = 0; i < n; i++) {
  Rant = R[0];
  Rnovo = ((R[0] >> 1) | Ri) & Masc[T[i]];
  R[0] = Rnovo;
  if ((Rnovo & 1) != 0)
    printf("Casamento exato na posicao %ld\n", i + 1);
  for (j = 1; j <= k; j++) {
    Rnovo = ((R[j] >> 1) & Masc[T[i]]) | Rant | Ri;
    Rant = R[j];
    R[j] = Rnovo;
  }
  if ((Rnovo & 1) != 0)
    printf("Casamento aproximado na posicao %ld\n", i + 1);
}
  • Saiu ((Rant | Rnovo) >> 1), que era substituição e retirada juntas.
  • Rant fica, porque a inserção usa o Rj-1 antigo. Por isso Rant = R[0] e Rant = R[j] continuam.
  • O novo printf logo depois de R[0] = Rnovo mostra as exatas.

P1Questão 1 (8 pontos): BMHS com a última ocorrência

Faça o módulo long BMHS(TipoTexto T, long n, TipoPadrao P, long m) que retorne a posição no texto T (de tamanho n) da última ocorrência do padrão P (de tamanho m), seguindo o funcionamento do BMHS visto em aula. Considere que o primeiro caractere do texto está na posição 1. Se não houver o padrão no texto, retorne 0.

Ver resolução

É o BMHS dos slides com uma variável ultima: cada casamento sobrescreve a anterior, então no fim sobra a última.

/* T: texto    n: tamanho do texto */
/* P: padrão   m: tamanho do padrão */
/* i: fim da janela   k: posição em T */
/* j: posição em P   d: tabela de deslocamentos */
long BMHS(TipoTexto T, long n, TipoPadrao P, long m)
{ long i, j, k, d[MAXCHAR + 1], ultima = 0;
  for (j = 0; j <= MAXCHAR; j++) d[j] = m + 1;
  for (j = 1; j <= m; j++) d[P[j-1]] = m - j + 1;
  i = m;
  while (i <= n)
  { k = i;
    j = m;
    while (j > 0 && T[k-1] == P[j-1]) { k--; j--; }
    if (j == 0) ultima = k + 1;   /* guarda o início do casamento */
    i += d[T[i]];
  }
  return ultima;                  /* 0 se nunca casou */
}
  • Mudanças em relação ao slide: tipo de retorno long, a variável ultima e o return.
  • Coloquei j > 0 antes da comparação para nunca acessar P[-1]. O slide escreve na ordem inversa; as duas são aceitas em sala, mas essa é mais segura.
  • Variação possível: percorrer de trás para frente e parar no primeiro casamento. Mas aí o algoritmo deixa de ser o BMHS "como apresentado em sala", então a versão acima é a mais segura para a prova.

P2Questão 2 (6 pontos): Boyer-Moore e BMH

Texto T = "ABRCCABABRACCAABRACCA" e padrão P = "BRACC".

a) (3 pontos) Passo a passo da pesquisa com Boyer-Moore, heurística ocorrência.
b) (3 pontos) Passo a passo com BMH, apresentando antes a tabela de deslocamento.

Ver resolução do item a

Regra da heurística ocorrência: compara de trás para frente. Na colisão, procura no padrão, à esquerda do ponto de colisão, o caractere do texto que colidiu e alinha os dois. Se não existir, o padrão passa inteiro por cima dele.

Verde: casou. Vermelho: colisão. Casamentos nas posições 9 e 16. Depois de um casamento, a convenção usada aqui é andar 1 posição.

Ver resolução do item b

Tabela de deslocamento (m = 5; entram os 4 primeiros caracteres, B R A C):

d[B] = 4d[R] = 3d[A] = 2d[C] = 1demais = 5

O salto sempre usa o caractere do texto alinhado com o último caractere do padrão, não importa onde houve a colisão. Casamentos nas posições 9 e 16.

P3Questão 3 (6 pontos): Shift-And só com retirada

Dado o código do Shift-And aproximado (inserção, substituição e retirada), altere-o para retornar as ocorrências exatas e as ocorrências aproximadas considerando k erros de apenas retirada.

/* k: máximo de erros   R[j]: máscara com j erros */
/* Ri: 10^(m-1), liga o 1º bit */
/* Rant: R[j-1] antigo   Rnovo: R novo */
/* Masc: máscaras   i: índice no C (de 0) */
for (j = 1; j <= k; j++) {
  Rnovo = ((R[j] >> 1) & Masc[T[i]]) | Rant | ((Rant | Rnovo) >> 1) | Ri;
  Rant = R[j];
  R[j] = Rnovo;
}
Ver resolução

Na fórmula original, cada pedaço é uma operação:

  • Rant (Rj-1 antigo): inserção. Sai.
  • Rant >> 1: substituição. Sai.
  • Rnovo >> 1 (R'j-1, já atualizado): retirada. Fica.
/* k: máximo de erros   R[j]: máscara com j erros */
/* Ri: 10^(m-1), liga o 1º bit */
/* Rnovo: R novo (antes da atribuição, o do nível anterior) */
/* Masc: máscaras   i: índice no C (de 0) */
Ri = 1 << (m - 1);
for (i = 0; i < n; i++) {
  Rnovo = ((R[0] >> 1) | Ri) & Masc[T[i]];
  R[0] = Rnovo;
  if ((Rnovo & 1) != 0)
    printf("Casamento exato na posicao %ld\n", i + 1);
  for (j = 1; j <= k; j++) {
    Rnovo = ((R[j] >> 1) & Masc[T[i]]) | (Rnovo >> 1) | Ri;
    R[j] = Rnovo;
  }
  if ((Rnovo & 1) != 0)
    printf("Casamento aproximado na posicao %ld\n", i + 1);
}
  • Rant não é mais necessário: só servia para inserção e substituição.
  • Dentro do laço, antes da atribuição, Rnovo ainda guarda o R' do nível anterior, que é exatamente o que a retirada usa.
  • O teste logo após atualizar R[0] dá as ocorrências exatas; o teste no fim dá as aproximadas (com até k retiradas). A inicialização R[j] = 1j0m-j continua igual.

b) (6 pontos) a partir do vetor resultado, os vetores Base e Offset.

N1Código: BMH que conta ocorrências

Faça o módulo long BMH(TipoTexto T, long n, TipoPadrao P, long m) que retorne a quantidade de ocorrências do padrão P no texto T, seguindo o método Boyer-Moore-Horspool.

Ver resolução 
/* T: texto    n: tamanho do texto */
/* P: padrão   m: tamanho do padrão */
/* i: fim da janela   k: posição em T */
/* j: posição em P   d: tabela de deslocamentos */
long BMH(TipoTexto T, long n, TipoPadrao P, long m)
{ long i, j, k, d[MAXCHAR + 1], cont = 0;
  for (j = 0; j <= MAXCHAR; j++) d[j] = m;
  for (j = 1; j < m; j++) d[P[j-1]] = m - j;
  i = m;
  while (i <= n)
  { k = i;
    j = m;
    while (j > 0 && T[k-1] == P[j-1]) { k--; j--; }
    if (j == 0) cont++;
    i += d[T[i-1]];
  }
  return cont;
}

Os pontos que a correção olha: d[j] = m; laço até j < m (o último caractere fica de fora); salto por T[i-1].

N2Código: Shift-And que retorna a primeira ocorrência

Faça o módulo long ShiftAnd(TipoTexto T, long n, TipoPadrao P, long m) que retorne a posição (começando em 1) da primeira ocorrência exata de P em T usando o Shift-And. Se não houver, retorne 0.

Ver resolução 
/* T: texto    n: tamanho do texto */
/* P: padrão   m: tamanho do padrão */
/* Masc: máscaras   R: prefixos que casam */
/* Ri: 10^(m-1)   i: índice no C (de 0) */
long ShiftAnd(TipoTexto T, long n, TipoPadrao P, long m)
{ long Masc[MAXCHAR], i, R = 0, Ri = 1 << (m - 1);
  for (i = 0; i < MAXCHAR; i++) Masc[i] = 0;
  for (i = 1; i <= m; i++) Masc[P[i-1] + 127] |= 1 << (m - i);
  for (i = 0; i < n; i++)
  { R = (((unsigned long)R >> 1) | Ri) & Masc[T[i] + 127];
    if ((R & 1) != 0) return i - m + 2;   /* início da ocorrência */
  }
  return 0;
}

O último bit ligado indica que o padrão terminou na posição i + 1; o início é i + 1 - m + 1 = i - m + 2. Se a questão pedir a posição final, retorne i + 1.
