Casamento de Cadeias

Como achar um pedaço de texto dentro de um texto maior. Do jeito mais ingênuo até os truques com bits. Cada algoritmo tem a ideia, o código em C linha por linha e um simulador para você mexer.

1O problema

Uma cadeia é só uma sequência de caracteres. Esses caracteres vêm de um conjunto chamado alfabeto. Numa cadeia de bits, o alfabeto é {0, 1}. Num texto em português, são as letras, os números e a pontuação.

Casamento de cadeias (ou casamento de padrão) é encontrar todas as ocorrências de um padrão dentro de um texto. É o que acontece quando você aperta Ctrl+F.

Texto T

T[0..n-1]

Tamanho n. É onde se procura.

Padrão P

P[0..m-1]

Tamanho m ≤ n. É o que se procura.

Alfabeto Σ

Σ = {a, b, ..., z}

Finito, de tamanho c. Os caracteres de P e T saem daqui.

Onde isso é usado: editores de texto, sistemas de busca (recuperação de informação) e biologia computacional, procurando trechos em sequências de DNA.

2Estrutura de dados

Todos os códigos da matéria usam estas definições. Clique nas linhas para ver o que cada uma significa.

Pegadinha de índiceOs slides contam as posições a partir de 1, mas o vetor em C começa em 0. Por isso, quando o algoritmo pensa na "posição k", o código acessa T[k-1]. Guarde isso: metade das dúvidas nos códigos vem daqui.

  • árvores TRIE e árvores PATRICIA;

4Arquivo invertido

É o índice mais usado. Tem duas partes:

  • Vocabulário: o conjunto das palavras distintas do texto.
  • Ocorrências: para cada palavra, a lista das posições onde ela aparece.

1 7 16 22 26 36 45 53 Texto exemplo. Texto tem palavras. Palavras exercem fascínio.

exemplo7

palavras26, 36

texto1, 16

Quanto espaço ocupa

  • O vocabulário é pequeno. A lei de Heaps prevê seu tamanho: V = K·nβ = O(nβ), com K entre 10 e 100 e β entre 0 e 1 (na prática, entre 0,4 e 0,6). Ou seja, cresce mais ou menos com a raiz quadrada do tamanho do texto.
  • As ocorrências ocupam muito mais: O(n), porque cada palavra do texto aparece uma vez em alguma lista. Na prática, de 30% a 40% do tamanho do texto.

Como a pesquisa funciona

  1. Pesquisa no vocabulário: as palavras da consulta são isoladas e procuradas no vocabulário.
  2. Recuperação das ocorrências: pega as listas das palavras encontradas.
  3. Manipulação das ocorrências: processa as listas para tratar frases, proximidade ou operações lógicas (E, OU).

Como tudo começa pelo vocabulário, ele costuma ficar num arquivo separado, que geralmente cabe na memória principal.

Palavra simples

Qualquer estrutura eficiente serve. Hashing e TRIE custam O(m) (m = tamanho da consulta, não importa o texto). Árvore B custa O(log n), mas guardar as palavras em ordem é barato e competitivo.

Frase

Mais difícil. Cada palavra é pesquisada separadamente e as listas são percorridas em sincronia, procurando posições em que as palavras aparecem em sequência.

Exemplo com TRIE

Para o mesmo texto ("Texto exemplo. Texto tem palavras. Palavras exercem fascínio."), cada palavra lida é pesquisada na TRIE. Se não está lá, é inserida com uma lista nova contendo sua posição. Se já está, a posição nova vai para o fim da lista dela.

6Força bruta

O mais simples de todos: tenta casar o padrão em toda posição do texto. Começa na posição 1, compara letra por letra; se falhar, anda uma casa e recomeça.

Simulador: força brutacompara da esquerda para a direita

Análise

  • Pior caso: Cn = m × n. Exemplo: P = aab e T = aaaaaaaaaa. Em toda posição, compara quase o padrão inteiro antes de falhar.
  • Caso esperado: (c / (c-1)) · (1 - 1/cm) · (n - m + 1) + O(1), bem melhor que o pior caso, porque normalmente a diferença aparece logo no 1º ou 2º caractere.
  • Num experimento de Baeza-Yates (1992), com texto aleatório e alfabeto de tamanho 4, o número esperado de comparações por caractere foi cerca de 1,3.

7Boyer-Moore (BM)

O algoritmo clássico, de 1977. A ideia que muda tudo: comparar a janela de trás para frente. Se aparecer uma diferença, em vez de andar só uma casa, calcula um deslocamento maior. Se não aparecer diferença, achou uma ocorrência.

O BM propõe duas heurísticas para calcular o deslocamento. Exemplo dos slides: P = cacbac, T = aabcaccacbac. Na primeira janela, o c do texto (posição 3) colide com o b do padrão.

Heurística ocorrência

Alinha o caractere do texto que causou a colisão com o 1º caractere igual a ele no padrão, à esquerda do ponto de colisão.

No exemplo: a colisão foi com c, então a janela anda até um c do padrão ficar embaixo desse c do texto.

Heurística casamento

Ao mover o padrão, faz a janela casar com o pedaço do texto que já tinha casado antes da colisão.

No exemplo: já tinha casado ac; a janela anda até outro ac do padrão ficar embaixo dele.

Receita da heurística ocorrência (é a que cai na prova)

  1. Encaixe o padrão no começo do texto.
  2. Compare da direita para a esquerda. Se todos casarem: achou (anote a posição de início) e ande 1 posição.
  3. Na primeira diferença, olhe o caractere do texto que colidiu (chame de x).
  4. Procure x no padrão, só à esquerda do ponto de colisão, começando do mais próximo.
    • Achou: ande o necessário para esse x do padrão ficar embaixo do x do texto. O salto é a distância entre as duas posições no padrão.
    • Não achou: o padrão passa inteiro por cima do x. O salto é (posição da colisão no padrão).
  5. Repita até a janela passar do fim do texto.
Exemplo do slide, em númerosP = cacbac, T = aabcaccacbac. Compara c=c, a=a, e colide na posição 4 do padrão (b) com o c do texto. À esquerda da posição 4, o c mais próximo está na posição 3. Salto = 4 - 3 = 1. Na janela seguinte (começando na posição 2), a colisão é entre o a da posição 5 do padrão e um c do texto; o c mais próximo à esquerda da posição 5 está na posição 3: salto 5 - 3 = 2. Continuando, o padrão casa na posição 7. Confira no simulador abaixo.
Diferença para o BMHNo BM ocorrência, o caractere usado é o da colisão, e a busca no padrão é à esquerda do ponto de colisão. No BMH, o caractere é sempre o do fim da janela, e o salto vem da tabela. Por isso os dois dão saltos diferentes quando a colisão não acontece logo no último caractere.
Espaço é caractereEm textos como "AUTONOMIA DA IA NA GRECIA", cada espaço ocupa uma posição (aqui, 10, 13, 16 e 19) e entra nas comparações normalmente. Na tabela de deslocamento, o espaço é só mais um caractere: se não está no padrão, recebe o valor padrão (m no BMH, m + 1 no BMHS).

O BM escolhe a heurística que dá o maior deslocamento. O problema: fazer essa escolha custa comparações a cada colisão, o que pesa no tempo. Ao longo dos anos surgiram simplificações, e as melhores usaram só a heurística ocorrência. É daí que vêm o BMH e o BMHS.

8Boyer-Moore-Horspool (BMH)

Em 1980, Horspool simplificou o BM e o deixou mais rápido. Pela implementação simples e eficiência comprovada, o BMH é o indicado para uso geral em casamento exato.

A ideia em uma fraseQualquer caractere já lido serve para consultar a tabela de deslocamentos. Horspool usa sempre o caractere do texto que está alinhado com o último caractere do padrão (o fim da janela), não importa onde a comparação falhou.

Tabela de deslocamentos

  1. Todo caractere começa com deslocamento m.
  2. Para os m - 1 primeiros caracteres do padrão: d[x] = m - j, a distância do caractere até o fim do padrão. Se a letra aparece mais de uma vez, fica a menor distância (a ocorrência mais à direita).
d[x] = min{ j tal que (j = m) | (1 ≤ j < m e P[m - j] = x) }

Exemplo: P = teste (m = 5). O último e fica de fora.

O t aparece duas vezes: vale a menor, 1. Resultado: d[t] = 1, d[e] = 3, d[s] = 2 e d[x] = 5 para qualquer outro caractere.

Por que o último caractere fica de fora?Se ele entrasse, teria distância 0 e a janela ficaria parada para sempre quando o fim da janela fosse igual ao fim do padrão.

9Boyer-Moore-Horspool-Sunday (BMHS)

Em 1990, Sunday propôs uma variante do BMH. A única mudança de ideia: o salto usa o caractere do texto logo depois do último caractere do padrão (o 1º fora da janela).

BMH

Valor inicial: m
Entram os m - 1 primeiros caracteres
Salto: m - j
Consulta: d[T[i-1]], fim da janela

BMHS

Valor inicial: m + 1
Entram todos os m caracteres
Salto: m - j + 1
Consulta: d[T[i]], depois da janela

d[x] = min{ j tal que (j = m + 1) | (1 ≤ j ≤ m e P[m + 1 - j] = x) }

Exemplo: P = teste. Distâncias contadas a partir da posição depois do padrão: t = 5, e = 4, s = 3, t = 2, e = 1. Ficam as menores: d[t] = 2, d[e] = 1, d[s] = 3 e d[x] = 6 para os outros.

10Autômatos

Um autômato é um modelo de computação bem simples: um conjunto de estados ligados por setas com letras. Você lê o texto letra por letra e vai seguindo as setas. Ele é a base para entender o Shift-And.

Um autômato finito é a tupla (Q, I, F, Σ, T):

  • Q: conjunto finito de estados;
  • I: estado inicial (I ∈ Q);
  • F: conjunto de estados finais (F ⊆ Q), desenhados com círculo duplo;
  • Σ: alfabeto de entrada;
  • T: função de transição. Para cada estado e cada símbolo de Σ ∪ {ε}, diz para quais estados se vai. ε é a transição vazia.

Não determinista

T(q, α) = {q1, ..., qk} com k > 1 para algum estado, ou existe alguma transição ε. Pode ter vários estados ativos ao mesmo tempo. Casamento aproximado é resolvido com esse tipo.

Determinista

T(q, α) = {q1}: para cada caractere, um único destino. Tem no máximo um estado ativo por vez.

Conceitos que caem

  • Cadeia reconhecida: existe um caminho do estado inicial até um estado final rotulado com ela.
  • Linguagem reconhecida: o conjunto de cadeias que o autômato reconhece. Nos autômatos acima: {a} e {abc} (no da direita, {d} e {abc}).
  • Estado ativo: se a cadeia x leva de I até q, então q está ativo depois de ler x.
  • Transições vazias (ε): andam sem ler caractere. Simplificam a construção, e sempre existe um autômato equivalente sem elas.
  • Acíclico (sem ciclos) e cíclico (com ciclos). Cíclicos são úteis para expressões regulares e podem reconhecer linguagens infinitas, como {ba, bba, bbba, ...}.

Buscar um padrão é simular um autômato

O autômato determinista abaixo reconhece P = aabc com Σ = {a, b, c}. Começa no estado 0; para cada caractere do texto, segue a seta. Chegou no estado 4: achou aabc. Cada caractere é lido uma vez, então o tempo é O(n). O espaço é m + 1 vértices e |Σ| × m arestas.

11Shift-And exato

O Shift-And usa paralelismo de bit: guarda vários valores lado a lado dentro de uma única palavra do computador (um long) e atualiza todos de uma vez com uma operação de bits.

As operações de bits

NotaçãoSignificadoExemplo
0 13Repetição (exponenciação)013 = 0111 · 104 = 10000
|OU bit a bit1010 | 0110 = 1110
&E bit a bit1010 & 0110 = 0010
>>Desloca para a direita, entra 0 à esquerdab1 b2 ... bc >> 2 = 0 0 b1 ... b(c-2)

A ideia

O algoritmo mantém o conjunto de todos os prefixos do padrão que casam com o final do texto já lido. Esse conjunto é a máscara R = (b1 b2 ... bm):

O que significa cada bitbj = 1 se e somente se os j primeiros caracteres do padrão (p1 ... pj) são iguais aos últimos j caracteres lidos do texto. Quando bm (o último bit) liga, o padrão inteiro casou.

Isso é exatamente simular o autômato não determinista que reconhece os prefixos do padrão: cada bit de R é um estado, e bit 1 é estado ativo. O laço Σ no estado 0 significa que um casamento novo pode começar a qualquer momento.

Passo 1: as máscaras M (pré-processamento)

Para cada caractere do padrão, uma máscara com 1 nas posições em que ele aparece. Para P = teste:

12345
M[t]10010
M[e]01001
M[s]00100

M[t] = 10010 porque o t aparece nas posições 1 e 4. Qualquer caractere fora do padrão tem máscara 00000.

Passo 2: a pesquisa

R começa com 0m. Para cada caractere lido do texto:

R' = ((R >> 1) | 10m-1) & M[T[i]]

R >> 1

Cada prefixo que casava "tenta crescer" uma letra: o bit j vai para a posição j + 1.

| 10m-1

Liga o 1º bit. A cadeia vazia ε também é sufixo, então um casamento pode começar em qualquer posição.

& M[T[i]]

Filtra: só fica o prefixo j + 1 se a letra lida for igual a pj+1.

Com paralelismo de bit, a nova máscara sai em O(1). Logo, a pesquisa toda custa O(n), desde que o padrão caiba em poucas palavras do computador.

12Casamento aproximado

Agora o padrão pode aparecer com erros. São três tipos de operação:

Inserção

Um caractere a mais no meio. tes te: espaço inserido entre o 3º e o 4º caractere.

Substituição

Um caractere trocado. testa: o último caractere virou a.

Retirada

Um caractere a menos. este: o 1º caractere foi retirado.

Distância de edição

ed(P, P') é o menor número de operações para transformar P em P' (ou o contrário). Exemplo: ed(teste, estende) = 4: retira o primeiro t e insere nde no fim.

O problema formal: achar todas as ocorrências de P' no texto com ed(P, P') ≤ k, onde k é o limite de erros.

  • Só faz sentido para 0 < k < m. Com k = m, qualquer trecho de tamanho m vira P trocando os m caracteres. Com k = 0, é casamento exato.
  • Nível de erro: α = k / m, a fração do padrão que pode mudar. Em geral, α < 1/2.
  • É modelado com autômatos não deterministas, e os algoritmos usam paralelismo de bit.

O autômato com erros

Cada linha do autômato é um número de erros. Pular de uma linha para a de baixo gasta um erro. Ligue e desligue cada tipo de aresta:

13Shift-And aproximado

Simula o autômato com erros usando paralelismo de bit. Cada linha do autômato vira uma máscara: R0 (exato), R1 (um erro), ..., Rk (k erros). São k + 1 máscaras.

Inicialização

R0 = 0m Rj = 1j0m-j (0 < j ≤ k)

Atualização para cada caractere lido

R'0 = ((R0 >> 1) | 10m-1) & M[T[i]] R'j = ((Rj >> 1) & M[T[i]]) | Rj-1 | (Rj-1 >> 1) | (R'j-1 >> 1) | 10m-1
Pedaço da fórmulaAresta do autômatoOperação
(Rj >> 1) & M[T[i]]HorizontalCasa um caractere no mesmo nível
Rj-1VerticalInserção

Atenção: R antigo ou R novo?Inserção e substituição usam Rj-1 (antes de ler o caractere). A retirada usa R'j-1 (já atualizado), porque é uma transição vazia: acontece no mesmo instante, sem consumir texto.

Nos exemplos dos slides, os exercícios escolhem quais erros valem. Só inserção (k = 1):

R'1 = ((R1 >> 1) & M[T[i]]) | R0 | 10m-1

Inserção, substituição e retirada (k = 1):

R'1 = ((R1 >> 1) & M[T[i]]) | R0 | (R0 >> 1) | (R'0 >> 1) | 10m-1

Como preencher uma linha da tabela à mão

A questão típica dá a tabela com as colunas (R0 >> 1) | 10m-1, R'0, R1 >> 1 e R'1. Use sempre os valores da linha de cima como R0 e R1 (na 1ª linha: R0 = 0m e R1 = 10m-1).

Exemplo: P = MIA (m = 3), k = 1, com os três erros. Máscaras: M[M] = 100, M[I] = 010, M[A] = 001, outros = 000. Vamos preencher a linha do I (posição 8 de "AUTONOMIA..."). A linha de cima (do M) terminou com R'0 = 100 e R'1 = 110.

Dicas para não errar
  • Nos termos de inserção e substituição use o R0 da linha de cima; no de retirada, use o R'0 da linha atual (que você acabou de calcular).
  • Se a questão pedir só alguns erros, monte o R'1 só com os termos deles (veja a tabela da receita acima).
  • Casamento exato: último bit de R'0. Aproximado: último bit de R'1. Toda posição exata também aparece como aproximada.
  • Confira digitando o padrão e o texto no simulador logo acima.

Retornar a primeira ocorrênciaNo teste de casamento, return da posição. Depois do laço, return 0;
Retornar a última ocorrênciaCrie long ultima = 0;. No teste, ultima = posição;. No fim, return ultima;

Mudar o tipo de retornoTroque void pelo tipo pedido (normalmente long) na assinatura.
Exemplo: BMHS com a última ocorrência (Prova 2024/1)
long BMHS(TipoTexto T, long n, TipoPadrao P, long m) { long i, j, k, d[MAXCHAR + 1], ultima = 0; /* novo */ for (j = 0; j <= MAXCHAR; j++) d[j] = m + 1; for (j = 1; j <= m; j++) d[P[j-1]] = m - j + 1; i = m; while (i <= n) { k = i; j = m; while (j > 0 && T[k-1] == P[j-1]) { k--; j--; } if (j == 0) ultima = k + 1; /* mudou */ i += d[T[i]]; } return ultima; /* novo */ }
O que decorar de cada código
  • BMH: d[j] = m; laço j < m com m - j; salto d[T[i-1]].
  • BMHS: d[j] = m + 1; laço j <= m com m - j + 1; salto d[T[i]].
  • Shift-And: Masc[P[i-1] + 127] |= 1 << (m - i); R = ((R >> 1) | Ri) & Masc[T[i] + 127]; teste R & 1.
